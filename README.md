## 又要开坑?
本人闲来无事开了个朋友服，但是我发现后续如果要添加/移除mod的时候需要和客户端保存一致，需要叫朋友们手动操作，或者重新打包整合包

*这很不方便*

于是，这个项目诞生了

## 干什么的？
这个项目旨在使用**增量更新**的方式维护MC客户端版本实例，让客户端和服务的同步变得更简单

#### 通用功能

- [ ] 对实例MOD情况进行版本跟踪

#### 基于增量更新包

- [ ] 对客户端实例进行MOD的`增加/替换/禁用/删除`
- [ ] 修改客户端`TOML/JSON`配置文件
- [ ] 自动检测增量更新包对实例的适配性
